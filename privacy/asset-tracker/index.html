asset-tracker 개인정보처리방침

마지막 수정 2026-11-21

이 앱

  • 운영자 한 명이 자기 자산과 가계부를 기록하려고 만든 개인 도구 (화면 이름: 자산 수익률 기록)
  • 다른 사람에게 제공하지 않음. Google 계정을 연결하는 사람은 운영자 본인뿐

정보가 오가는 길

  1. Gmail뱅크샐러드 내보내기 메일만 검색
  2. 메일 제목, 받은 시각, zip 첨부 (읽기 전용)
  3. 운영자 서버zip을 풀어 가계부 엑셀 저장, 기존 기록과 합침
  4. 자산 기록 화면 (인터넷에 공개하지 않은 사설망)
  5. 운영자 기기휴대폰과 노트북 브라우저

Google에서 받는 정보

  • 요청하는 권한: Gmail 읽기 전용 (gmail.readonly)
  • 이 권한으로는 메일을 보내거나 지우거나 고치지 못함
  • 권한 범위는 메일 전체 읽기지만, 앱은 첨부가 zip이고 "banksalad" 또는 "뱅크샐러드"가 들어간 메일만 검색함
  • 검색에 걸리지 않은 메일은 받아 오지 않음
  • 검색에 걸린 메일에서 저장하는 것: zip 첨부에서 꺼낸 가계부 엑셀, 메일 제목, 받은 시각, 메일 고유 번호

쓰는 곳

  • 운영자의 자산 기록 화면에 가계부 내역을 반영하는 데에만 씀
  • 광고, 판매, 외부 분석 서비스, AI 모델 학습에 쓰지 않음

저장과 보관

  • 받은 파일과 Google 접근 토큰은 운영자 소유 기기에만 저장함: 운영자가 관리하는 클라우드 서버 한 대, 운영자 노트북
  • 서버 파일은 운영자 계정만 읽을 수 있게 권한을 막아 둠
  • 서버 화면은 인터넷에 열려 있지 않고, 운영자 기기끼리만 연결되는 사설망으로만 열림
  • 보관 기간: 운영자가 지울 때까지

공유

  • 누구에게도 넘기거나 팔지 않음
  • Google API에서 받은 정보의 사용과 전송은 Google API Services User Data Policy의 Limited Use 요건을 따름

연결 끊기와 삭제

  • Google 계정의 타사 연결 화면에서 asset-tracker를 삭제하면 바로 접근이 끊김
  • 서버에 저장한 파일은 운영자가 직접 지움
